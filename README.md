## Challenge 1

As you might notice, I added an animated hamburger menu. I thought it would be a fun addition, but it turned out to be more trouble than it was worth. I spent hours trying to get it working after watching tutorials, and even then it was tough to implement on my site. Still, I kept it in because I'd already put in so much effort.

I also realized a bit late that the project needed at least three visuals—so I went ahead and added plenty. Most of my time went into designing the charts and adding accurate data. I got some help from a friend who studies Physics and Astronomy in Amsterdam, which made the data pretty reliable.

For the design, I mainly used flexbox, which made it easy to place containers side by side on larger screens. I used Chart.js for the visualizations, with line charts to show changes in speed and bar charts for variety. I took some inspiration from Pinterest for the space-themed style.

There's still one bug I can't fix: on my iPhone, one of the containers behaves strangely, even though it looks fine when I inspect it with iPhone dimensions on my computer.

## Challenge 2

For this challenge, I decided to push myself and create an analog clock. I built it with the help of some YouTube videos, but the styling—including the day/night indicator circle—was entirely my own. I also added a few simple animations and a digital clock for fun.

## Challenge 3

I browsed through several APIs to find the most useful ones. I ended up using the Weather API because it was the most straightforward, and I combined it with a sunrise/sunset API. I pull the longitude and latitude from the weather API and pass that data into the sunrise/sunset API's URL.

For this challenge, I focused more on using a grid layout. It took some getting used to, but it works well for certain layouts. I chose to have a search bar without a separate search button, making it easy to use: you just click away or hit a key to trigger the data fetch. You can also switch between Celsius and Fahrenheit.

I also added a scoring system. I came up with the idea after talking to the same friend who helped with the data—he suggested what should be most important. The score is based on a few calculations for each state. It's not the most accurate, but I thought it was a fun addition.
